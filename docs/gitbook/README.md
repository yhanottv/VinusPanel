# 🏠 VinusPanel

Le guide d'installation, d'utilisation et de maintenance du thème open source VinusPanel pour Pterodactyl.

**Cette documentation couvre la branche `main`.** Elle décrit l'installation complète d'un VPS vierge, de la première commande à un panel sécurisé avec Wings, Blueprint et le catalogue Minecraft.
