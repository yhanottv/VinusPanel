# Static presentation fixtures

Rendered VinusPanel 3.2.0 markup and styles, captured from the theme and stripped of scripts, session state, active links and personal data. All server/account values are demonstration data. These files are presentation fixtures, not an interactive panel or an installation package. The console is shown offline; its canvas history is not replayed.

Used by the Higgsfield media workflow to render the public gallery. Assets reference the public repository only. Serve this directory over HTTP to inspect the layouts.
